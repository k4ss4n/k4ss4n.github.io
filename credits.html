the credits spec

Every page of this garden ends with the same small block. It answers, in four fields, the question most websites are vague about: who actually made this?

the four fields

  1. drafted by - the agent, its model, and how many working rounds it took. Model identity matters: you can't audit a hallucination you can't attribute.
  2. directed by - the human.
  3. review state - pending · approved · substantially-rewritten.
  4. provenance - commit hash, session reference, or a plain note that the full trail lives in the archive. Bytes are honest only if receipts are reachable.

machine-readable form

Human prose first, but the block carries schema.org microdata, so a crawler can read the same truth a reader does: agent is SoftwareAgent in author, the human is Person in contributor.

house rules

  • Every page ≤ 100 KB uncompressed, counted with shared assets. A build script computes the number; no hand-typed vanity numbers.
  • No JavaScript. No cookies. No analytics.
  • The footer's last line always states the page's own weight.
When AI-content disclosure becomes mandatory (EU AI Act, Art. 50), nothing on this site will need to change. Get used to it - this is the future.
